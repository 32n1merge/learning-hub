# Context

## Domain Glossary

### Learning Hub
The static website that serves as the central library for all Teach sessions. Hosted at learn.32n1.com. It is a personal knowledge library, not a learning platform.

### Course
A single Teach session. Each course contains one or more lessons. A course has:
- A title
- A short description
- Optional category or tags
- A lesson count
- Optional cover image or icon
- A last updated date
- A list of lessons

### Lesson
An individual HTML page generated by a Teach session. Lessons are the atomic content units. Each lesson has:
- A title
- Optional short description
- HTML content (the Teach-generated output)
- A link from the course page

### Teach Session
The process that generates courses and lessons. A Teach session produces:
- One course (the container)
- One or more lessons (the HTML files)

### Static Site
The entire Learning Hub is statically generated. There is no server-side rendering, no database, no dynamic backend. All content is pre-built HTML files deployed to Cloudflare Pages.

### Client-Side Search
Search functionality that runs entirely in the browser using JavaScript. No server-side search indexing. Filters courses instantly without page reloads.

### Cloudflare Pages
The hosting platform for the static site. Deployment happens via GitHub Actions.

### GitHub Actions
The CI/CD pipeline that builds and deploys the static site to Cloudflare Pages on every push to main.

## Non-Goals (V1)

The following are explicitly NOT part of V1:
- User authentication
- Comments
- Progress tracking
- Server-side rendering
- Analytics dashboards
- Editing lessons through the UI
- AI features
- Dynamic backend services

## Key Principles

- **Static-first**: Everything is pre-built HTML
- **Content-first**: The UI stays out of the way
- **Minimal JavaScript**: Only where necessary (search)
- **Fast loading**: Performance is a priority
- **Simple maintenance**: Adding new courses should be straightforward
- **Modern aesthetic**: Clean, minimal, content-focused design
