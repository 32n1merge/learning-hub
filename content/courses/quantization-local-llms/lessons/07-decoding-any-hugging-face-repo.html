Where to look before downloading

  1. Model card (README) — the author states what the file is, what it was calibrated on, and how to run it. No card = suspicious.
  2. Files tab — check the actual sizes. A "27B" repo whose Q4 file is 6 GB is mislabeled or broken; expected ≈ bpw × 27 / 8.
  3. config.json — architecture, context length, quantization_config. Multimodal models have a vision encoder; chat models have a chat template.
  4. Quantization method — is it calibrated (imatrix/UD/AWQ/GPTQ/SC) or naive? Calibrated wins at every bit level.
  5. Community signal — downloads, likes, recent comments, and "used in" datasets. On the HF search page, the ?local-app=llama.cpp view even shows hardware compatibility and a ready-made run command.

Red flags

  • File size wildly off the bpw math.
  • No model card, no license, no quantization_config.
  • Names that don't match content ("Qwen3.8-27B" that's actually a 1B Mistral).
  • Weird "premium" or "paywalled" reposts of official weights — everything here is Apache-2.0, free.
  • Old repos still shipping only Q4_0/Q4_1 when K-quants exist.
  • Bleeding-edge quant names with no benchmarks (the i1-* family is legit but young — check before adopting).
The 60-second check: open the repo → read the first 10 lines of the model card → look at file sizes → compare bpw math → check downloads. That's enough to separate a good quant from a trap 95% of the time.
